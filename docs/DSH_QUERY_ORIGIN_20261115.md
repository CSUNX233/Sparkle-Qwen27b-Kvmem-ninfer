# DSH 减法、查询来源与日常建议（2026-11-15）

当前建议：**继续使用 v1.2.0 引擎和精简后的 DSH；首次消息排序候选默认关闭。** 本轮不发布新引擎附件，不改模型、xhigh、采样、CPU 视觉、页池或 Host KV。不是“所有长任务质量均已提高”的结论。

## 已确认的问题与处理

DSH 的 `source.kind=plugin` 不会成为独立的 API 角色：pi-ai 最终把它编码为普通 `user`。旧状态卡会重复任务 `goal`；任务账本、待办催促和截图续作也会追加指令。已删除这三种本地提醒模块及截图钩子，禁用原生 `repeat-tool-reminder`，保留正常工具结果、执行校验、畸形调用停止保护和压缩失败停止保护。

另外，首次请求的真实任务之后还会排列 AGENTS、策略和技能目录等原生背景消息。`engine/src/models/qwen3_5/frontend/frontend.cpp` 按最后一条用户消息取查询，因此会取到技能目录。跨块查询组装不会自动识别消息来源。

`initial-context-order.mjs` 候选只在 `ninfer-local` 新会话首次接收纯文本时，把已识别的背景信息放在真实任务之前。没有新增或删改原文、没有提升消息角色、没有新增模型请求；后续直接使用已落库的顺序。已有请求、图片、计划模式、其他预设和未知来源保持原路径。**它修正了来源，但改变输入顺序也会改变推理路径，不能凭结构正确直接认定质量更好。**
