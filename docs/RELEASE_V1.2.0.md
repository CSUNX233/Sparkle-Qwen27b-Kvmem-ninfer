# v1.2.0：图片分块与长会话压缩修复

本版修复了 CPU 或 host-staged 视觉与 MTP 同时启用时的一种 `scatter` 形状错误，并为本地模型的摘要截断增加有界恢复。沿用 v1.1.0 的检索、量化、采样和公开默认页池；GPU 视觉可以显式选择，是否放得下取决于模型与显卡余量。

## 主要修复

- **图片分块边界**：图片的第一个视觉 token 恰在预填充分块边界时，当前块可能没有视觉 token，但 MTP 的下一列仍需要它。旧代码没有为这一列准备 host-staged 视觉暂存，从而产生 `scatter: expected src [D,V], indices [V], dst [D,T]`。修复确保下一列被分配并复制，且不增加启动规划中最坏情况的暂存上限。GPU 常驻视觉使用不同路径。
- **摘要截断恢复**：仅当 `ninfer-local` 的首次摘要因输出上限截断，丢弃不完整输出并以 low 思考强度重试一次该辅助摘要。首次摘要和正常对话的思考设置不变。重试仍截断、为空或缺少必要章节时，保留原历史并停止当前轮，避免在同一轮反复压缩。网络或其他错误仍须结合日志排查。
- **DSH 与安装**：恢复模型选择和思考强度界面；增加外部视觉模型的 GPU 视觉选项，并修复 Windows PowerShell 安装阶段的哈希检查兼容问题。既有 CPU 视觉和公开默认预算保持原样。

## 验证与边界

| 检查 | 结果与限制 |
|---|---|
| 图片边界真实模型对照 | 旧引擎的第 128 token 边界请求稳定报同一 `scatter`，修复版成功；相邻非边界请求的前 16 个贪心生成 token 一致。短对照不能证明所有任务质量相同。 |
| 显存 | 对照采样峰值旧版 11318 MiB、修复版 11320 MiB；安装后短测 11326 MiB。差异处于采样/运行波动范围，不能宣称严格零增量。 |
| 真实长任务 | 体素小镇任务带两张截图运行到约 212K 输入 token；旧版摘要以 xhigh 耗尽 8192 token，未生成完整 checkpoint。任务用于诊断，未完成游戏交付。 |
| 摘要恢复 | 回放实际失败会话的 64 条消息和 31 个工具定义：首次截断由测试注入，真实模型以 low 完成 135111-token 输入的摘要，八个章节齐全；DSH 压缩事务在隔离 Session 中写入并重新载入。token meter 为测试桩，并非持久化存储端到端验收。 |
| 压缩后续接 | 加载压缩后的会话与原两张截图，xhigh 调用测试工具并收到结果。首次运行第二轮有额外工具调用，严格复测直接结束；单次通过不能排除所有循环。 |
| 目标硬件 | 直接验证 Windows / RTX 5070 Ti Laptop 12GB 的 CPU 视觉；RTX 5060 Ti 16GB 的 GPU 视觉尚未实机验证。`sm120a` 二进制适用 RTX 50 系，其他架构需自行构建。 |

原故障电脑的引擎日志缺失，因此不能断定其每次同名错误都由上述边界触发。长任务、模拟和硬件测试均有范围，不宣称所有多图、压缩或工具调用问题已经解决。
